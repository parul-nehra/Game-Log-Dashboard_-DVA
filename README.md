# Game Log Dashboard - DVA

## Overview
This repository contains the **Game-Log-Dashboard_-DVA** project by Parul Nehra. It features an in-depth Tableau dashboard designed to analyze player behavior, monitor retention rates, and track monetization metrics for a gaming application. 

## Key Performance Indicators (KPIs)
The top of the dashboard tracks vital weekly game metrics, including:
* **Avg DAU** (Average Daily Active Users)
* **New Install Users**
* **ARPDAU** (Average Revenue Per Daily Active User)
* **Paid Players**
* **Total Revenue**

## Dashboard Features & Visualizations
The dashboard is divided into three core analytical sections:

### 1. Setup Moment Analysis
* **Tutorial Completion Rate %:** Analyzes how far users progress through different tutorial stages.
* **User Status by Tutorial:** Compares active versus inactive users based on their tutorial progression (with an adjustable churn window).
* **Day 1 Retention by User Cohort:** Tracks the percentage of users returning on their first day after installation.

### 2. Retention Analysis
* **Weekly Cohort Retention:** A detailed heatmap tracking user retention percentages over multiple weeks for different user cohorts.
* **Weekly Retention By Action:** A trend line visualizing user retention based on specific in-game actions (e.g., buff, gacha, level, lobby, purchase, shop, stage, tutorial).

### 3. Purchase Pattern Analysis
* **Item Purchases:** Bar charts displaying the popularity of different item categories (Buffs, Gacha, Weapons, Skills, Gold).
* **Items by Level:** Tracks which buffs or items are purchased by players at different level tiers.
* **Purchase Pattern by Weekdays:** A calendar heatmap revealing which days of the week generate the most revenue and transactions.
* **Conversion Rate (CVR):** Area charts tracking the user journey from the Shop to specific actions, such as Shop to Purchase CVR, Shop to Gacha CVR, and Shop to Buff CVR.
